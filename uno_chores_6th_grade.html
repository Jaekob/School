How to use this file:
1. Download picture-only images for each chore from irasutoya.com (search the Japanese or English chore name).
2. In this HTML file, find the matching <div class="img-placeholder" data-chore="..."> block and replace its text content with <img src="your-image.png">.
3. Open this file in a browser and print (Ctrl/Cmd+P). Each frequency group starts on its own page.
4. The corner icon is a pie-chart + label showing the frequency: Always = 100% full circle, Usually = 75%, Sometimes = 50%, Never = 0% (empty circle).
